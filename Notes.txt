Live fuzzy-matching search across records, colourful scrolling viewer with
in-record live search (matches colourised + underlined) and useful options
once a record is selected (search inside, re-search, add/update records, copy).

Quick start

  git clone https://github.com/jamieduk/Python_Cheat_Sheet.git
  cd Python_Cheat_Sheet
  ./setup          # makes everything executable, extracts records.zip (opt-in)
  ./menu           # the enhanced interactive J~Net menu (needs fzf)
  ./class-menu     # simple number-picking class menu
  ./search_records # standalone live fuzzy search

Dependencies

  fzf     — live matching / scrolling UI (required)
  bat     — colourful syntax-highlighted previews (recommended, optional)
  python3 — used by add_missing (pydoc) and preview underlining
  7za     — records compression (optional, only if you use records.zip)

Tools menu

  Compression   — zip / unzip the records folder with 7za
  Add Missing   — build a record from a Python module's pydoc (or a man page)
  Open Record   — live-search then open a single record in a pager
